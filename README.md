# AlmaCode Academy

Онлайн IT білім беру платформасының макеті — таза HTML, CSS және JavaScript (framework-сіз) арқылы жасалған көп беттік веб-сайт.

## Жобаның мақсаты

Онлайн курстар сататын білім беру платформасының толық жұмыс істейтін макетін жасау: каталог, курс беттері, іздеу/сүзгі жүйесі, кері байланыс формасы және responsive дизайн.

## Қолданылған технологиялар

- **HTML5** — семантикалық белгіленген құрылым
- **CSS3** — custom properties (design tokens), Grid/Flexbox, media queries
- **Vanilla JavaScript (ES6+)** — DOM манипуляциясы, localStorage, форма валидациясы
- Сыртқы кітапхана/фреймворк қолданылмаған

## Сайт құрылымы

```
├── index.html          Басты бет
├── about.html          Біз туралы
├── services.html       Қызметтер
├── catalog.html        Курстар каталогы (фильтр + іздеу)
├── course.html         Курс туралы толық ақпарат (?id= параметрі арқылы)
├── contact.html        Байланыс формасы
├── 404.html            Қате бет
├── css/
│   └── style.css       Барлық стильдер, дизайн-токендер, responsive
├── js/
│   ├── data.js         Курстар туралы деректер (массив)
│   ├── main.js         Header/nav, тема ауыстыру, dropdown, аккордеон, слайдер, модал
│   ├── catalog.js      Каталогты фильтрлеу, сұрыптау, іздеу логикасы
│   ├── course.js       Курс бетін динамикалық түрде рендерлеу
│   └── forms.js        Форма валидациясы (тіркелу модалы + байланыс формасы)
└── README.md
```

## Негізгі функционал

- **5 жеке бет**: Home, About, Services, Catalog, Contact (+ 404 және курс беті)
- **Динамикалық элементтер**: JavaScript арқылы карточка қосу, каталогты фильтрлеу, live іздеу
- **Фильтрация жүйесі**: санат және баға (range slider) бойынша сүзгі
- **Dark/Light Mode**: ауыстырғыш, таңдау `localStorage`-те сақталады
- **LocalStorage**: тема және тіл таңдауы браузер жабылғаннан кейін де сақталады
- **Form validation**: HTML5 + JavaScript арқылы қос деңгейлі тексеру (бос өріс, email форматы)
- **Responsive**: mobile / tablet / desktop үш breakpoint
- **SEO негіздері**: әр беттің жеке `<title>`, `<meta description>`, дұрыс heading иерархиясы, суреттерде `alt`
- **Accessibility**: `aria-*` атрибуттары, форма `label`-дары, пернетақтамен басқарылатын dropdown/модал/аккордеон
- **Интерактивтілік**: dropdown (тіл таңдау), accordion (курс бағдарламасы, FAQ), slider (баға сүзгісі және пікірлер слайдері), modal (тіркелу терезесі)

## Іске қосу жолы

Файлдарды кез келген статикалық сервер арқылы ашу жеткілікті:

```bash
# Python болса
python3 -m http.server 8000
# содан кейін браузерде http://localhost:8000 ашыңыз
```

Немесе `index.html` файлын тікелей браузерде ашуға болады.
